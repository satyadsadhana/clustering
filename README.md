# Clustering

Kumpulan notebook untuk persiapan UTS Data Mining II menggunakan K-Means.

## Isi

- [Audio](UTS_Datmin_II_Audio.ipynb): ekstraksi fitur audio dan clustering.
- [Image](UTS_Datmin_II_Image.ipynb): preprocessing gambar dan clustering.
- [Text](UTS_Datmin_II_Text.ipynb): preprocessing teks, TF-IDF, dan clustering.

## Cara pakai

1. Buka notebook di Google Colab atau Jupyter Notebook.
2. Install library yang diperlukan sesuai petunjuk di notebook.
3. Sesuaikan lokasi dataset, nama kolom jika diperlukan, dan konfigurasi.
4. Ikuti petunjuk di notebook dan jalankan cell secara berurutan.
